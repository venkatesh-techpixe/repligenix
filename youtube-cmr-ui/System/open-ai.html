Open AI Setup

How to configure OpenAI API credentials?
1
Step 1: Go to Official Website

Go to Open AI Official Website

2
Step 2: Create/Open an OpenAI Account
  • 1. If you already have an OpenAI account, click “Log in”
  • 2. Or Create OpenAI Account
3
Step 3: Add Billing Information (Required for API Access)
  • 1. Account Management
  • 2. Manage Billing Details
  • 3. Add credit/debit card under Payment methods

Note: You must add a valid card to use GPT-4 and related APIs.

4
Step 4: Generate API Key
  • 1. Go to API Keys page
  • 2. Click + Create new secret key
  • 3. Optionally name your key
5
Step 5: Copy and Save the Key
  • 1. The key will be shown only once
  • 2. Copy and store securely
6
Step 6: Submit Your Secret Key to Our Platform:

Save your generated secret key.
