YouTube API Setup

How to configure YouTube API credentials?
1
Step 1: Go to Google Cloud Console

Go to google developer console

2
Step 2: Select or Create a Project
  • 1. If you already have a project for your app select it
  • 2. If you don’t have one, click on Select a project and create a project
3
Step 3: Configure OAuth Consent Screen
  • 1. Click on OAuth consent screen
  • 2. Select "External" (for public users) and click Create.
  • 3. Fill out: App Name, User Support Email, Developer Contact Email
  • 4. Under Test Users, add the Gmail accounts of users who will test this.
  • 5. Under Scopes, click “Add or Remove Scopes” and add
- https://www.googleapis.com/auth/youtube.force-ssl - https://www.googleapis.com/auth/yt-analytics.readonly - https://www.googleapis.com/auth/youtube.readonly - https://www.googleapis.com/auth/yt-analytics-monetary.readonly

Note: If your app is not published, only test users can log in.

4
Step 4: Create OAuth 2.0 Credentials
  • 1. Go to Credentials
  • 2. Click “Create Credentials” → “OAuth client ID”
  • 3. Select Web Application.
  • 4. Give it a name (e.g., YouTube Reply Automation).
  • 5. Under Authorized redirect URIs, add bellow callback url
    - https://repligenix.com/user/channel/google/callback
  • 6. Click Create, and note down the credentials
    - Client ID
    - Client Secret
5
Step 5: Enable YouTube Data API
  • 1. Go to API Library
  • 2. In the search bar, type “YouTube Data API v3”
  • 3. Click the result
  • 4. If already enabled, you will see “API enabled”
  • 5. If not enabled, click Enable Note: YouTube Data API v3 works on a quota system. You get 10,000 units per day for free.
6
Step 6: Enable YouTube Analytics API
  • 1. Again in the search bar, type “YouTube Analytics API”
  • 2. Click the result
  • 4. If already enabled, you will see “API enabled”
  • 5. If not enabled, click Enable Note: YouTube YouTube Analytics API works on a quota system. You get 10,000 units per day for free.
7
Step 7: Create API Credentials
  • 1. Go to Credentials Page
  • 2. Click “Create Credentials” → “API key”
  • 3. If you've already created an API key earlier, you can use it
8
Step 8: Restrict Your API Key (Highly Recommended)
  • 1. Find your created API Key in the list and click on it.
  • 2. Application Restrictions
    - Choose IP addresses
    - Add your server's public IP address
  • 3. API Restrictions
    - Check Restrict Key
    - Select API: YouTube Data API v3
  • 4. Click Save
9
Step 9: Submit Your Credentials to Our Platform:

Save your generated Client ID, Client Secret and API key
